# Bambika v1.0 Scope

## In Scope
- Core Truth or Drink pass‑and‑play mechanic (2‑8 players)
- 5 official decks: Friends (free), Couples, Bachelorette, Office Safe, Sober Dare (Pro)
- Custom Decks: DeckEditor, card CRUD, free/pro limits
- Bambika Pro $7/month subscription (RevenueCat)
- QR deck sharing (Pro generates, all scan) – fully offline
- Sober Mode with dedicated sober_text
- Penalty labels: Drink/Shot/Sip/Dare
- Undo last card, per‑player drink tracking, results screen
- Card flip animation (Reanimated 2, 550ms)
- SQLite seed DB bundled – 100% offline from install
- MMKV for key‑value state
- Optional Firebase Auth, Crashlytics, Remote Config
- API 21+ (Android 5.1), <70MB APK
- English only (i18n‑ready)

## Out of Scope (v1.1+)
- iOS release
- Real‑time multiplayer
- Swahili content
- Mid‑game ads
- Spin the Bottle mode
- Category packs as individual IAPs
